# МОМЕНТ — витрина займов

Витрина микрозаймов для клиента (Telegram: Zakhar Lavrov). 24 МФО,
партнёрские ссылки клиента, панель управления каталогом.

## Что где

| Файл | Зачем |
|---|---|
| `index.html` | сама витрина |
| `css/style.css` | всё оформление |
| `js/app.js` | подбор, фильтры, каталог, лента, вопросы |
| `data.js` | **каталог**: тексты сайта, разделы, офферы |
| `panel.html` | панель управления (правка каталога) |
| `panel-schema.js` | какие поля у карточки в панели |
| `panel-core.js`, `panel-pass.js`, `gate.js`, `publish.js` | ядро панели, общее для всех витрин |
| `api.php`, `data.php`, `check.php` | сохранение из панели и отдача каталога мимо кеша |
| `img/logos/` | логотипы МФО и банков |
| `fonts/` | Onest и JetBrains Mono, лежат локально |

## Панель управления

`/panel.html`, пароль — в `.pass-note` (в гит не попадает).

- **С PHP на хостинге** — кнопка «Сохранить на сайт» пишет `data.js` сама,
  правки видны сразу. Пароль спрашивается при каждом входе, менять его можно
  в самой панели (раздел «Пароль»).
- **Без PHP (GitHub Pages)** — панель честно говорит, что публиковать некому,
  и работает как черновик: правки живут в браузере, кнопка «Скачать data.js»
  отдаёт готовый файл, его нужно залить на сайт.

Что правится: название сайта и тексты первого экрана, разделы каталога,
карточки (компания, сумма, ставка, срок, возраст, описание, плашки,
партнёрская ссылка, логотип), порядок карточек, скрытие карточки с сайта.

## Как устроен подбор

Сайт не хранит числа отдельно — он читает их из тех же строк, что видит
посетитель:

- «Сумма» → последнее число строки (`до 100 000 ₽` → 100000) — ползунок «Сумма»;
- «Срок» → последнее число (`7–30 дней` → 30) — ползунок «Срок»;
- «0%» в ставке или в плашке → карточка попадает в фильтр «Первый займ 0%»;
- «Плашки» карточек собираются в кнопки-фильтры над каталогом (шесть самых частых).

Поэтому формат строк лучше не ломать: пишите «до 100 000 ₽», а не «сто тысяч».

## Цифры в карточках

Суммы, ставки и сроки проставлены по публичным условиям МФО на сентябрь 2026.
**Перед запуском трафика сверьте их со своей партнёркой** и поправьте в панели:
недостоверная цифра — это и снятый оффер, и повод для штрафа.

У двух компаний (Лайм-Займ и «Привет, сосед») ссылок пока нет — на карточке
вместо кнопки стоит «Скоро». Как только ссылки появятся, впишите их в панели.

## Дальше: карты

Клиент обещал прислать дебетовые и кредитные карты. Для них:
добавьте раздел в панели («Добавить раздел» → название и надпись на кнопках),
логотипы банков уже лежат в `img/logos/` и доступны в списке панели.

## Доступность

Разметка проверена по WCAG 2.2 AA: подбор работает с клавиатуры, у ленты
логотипов есть кнопка паузы, фильтры — обычные чекбоксы, результат
объявляется живой областью, тёмный подвал и синий акцент держат контраст.
Ленту и каскад карточек выключает системное «меньше движения».
